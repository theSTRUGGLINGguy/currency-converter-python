Project Statement

Project Title

                     Currency Converter

Problem Statement:
-Converting money from one currency to another can be confusing when users have to manually search for exchange rates and perform calculations themselves. There is a need for a simple and user-friendly application that can perform currency conversions quickly and accurately.
-The Currency Converter project is a Python-based command-line application that allows users to convert an amount from one currency to another using predefined exchange rates. It also provides a list of supported currencies and maintains a record of previous conversions.

Project Scope:
-The project focuses on developing a simple and modular currency conversion system using Python.
The system will:
- Convert amounts between different supported currencies.
- Display the available currencies and their names.
- Validate user inputs and handle invalid entries.
- Store and display conversion history.
- Provide a simple menu-based command-line interface.
- Organize the project into multiple Python modules for better maintainability.
- Provide basic testing for the currency conversion functionality.

*The project does not currently use live exchange-rate APIs. The conversion rates are stored within the application and can be updated when required.*

Target Users:
The application is intended for:
- Students learning Python programming.
- Users who need quick currency conversions.
- Beginners who want a simple currency conversion tool.
- Users who want to understand basic currency conversion calculations.

High-Level Features

1. Currency Conversion

Users can enter an amount, select the source currency, and select the target currency. The application calculates and displays the converted amount.

2. Available Currencies

Users can view the list of currencies supported by the application along with their currency codes and names.

3. Input Validation

The system checks whether the entered amount and currency codes are valid and provides appropriate messages for invalid inputs.

4. Conversion History

The application stores previous conversions and allows users to view their conversion history.

5. Menu-Based Interface

Users can navigate through different functions using a simple command-line menu.

6. Modular Design

*The project is divided into separate Python modules for conversion, validation, currency data, history management, and display functions.*

Expected Outcome:
-The final system will provide a simple, functional, and modular currency converter that can perform currency conversions, validate user input, display supported currencies, and maintain conversion records.
